# 几何光线追迹核心

这是一个教学和方案验证用的 Python 几何光学核心，使用右手坐标系，光轴为 z。

## 简化模型

- 光线是携带波长、初始方向和标量权重的无限窄几何光线。
- 表面为平面或球面，绕 z 轴旋转对称，并带有限通光口径。
- 材料只提供折射率；内置常数折射率和 Sellmeier 色散。
- 折射使用三维矢量 Snell 定律，反射使用镜面反射定律。
- 每一步选择当前前进方向上最近、且在路径预算内的有效交点。
- 默认不计 Fresnel 反射率、膜层、吸收、偏振、散射、衍射、波前像差和制造公差。
- 标量能量账中，理想折射和反射保持权重，吸收边界将权重置零；TIR 和擦边事件保留光线结果但不臆造分裂光束。

状态包括 reached_image、grazing、total_internal_reflection、absorbed 和 no_image。未到达像面的光线仍完整保存交点和事件，便于排查口径、路径预算或最大交互次数。

## 使用

运行演示：python examples/demo.py

运行测试：pytest -q

演示会生成可重新打开的 engineering.json 和追迹结果 trace-results.json。后续可在稳定的表面/材料接口上加入点列图 RMS、光斑包络和多波长色差统计；当前结果不能直接作为镜头制造处方。
